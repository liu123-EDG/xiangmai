# 八音长卷与八族形态演示

位置：八音总览的开头介绍与八张档案卡之间；八个详情页的基本信息与正文之间。

## 体验

- 总览：原生滚动，八幕固定画面，山景分层视差，线条绘制、图形与文字逐层显现。反向滚动可回看，底部族名按钮可跳到任一幕，画面链接进入正确档案。
- 详情：每族都有自己的 SVG 示意和三段讲解，滚动或按钮选择控制层次。天琴的弹唱舞与铜铃、马头琴的琴头弓弦、侗族大歌的众低独高、新城戏的八角鼓与舞台、苗族古歌的记忆主题、彝族山歌的问答、章哈的口头叙事、格萨尔的版本分支。
- 手机：总览上下布局，民族导航分两行；详情图形随阅读固定。
- 减少动态：总览全部八幕顺序阅读，图形完整可见；关闭固定和视差。
- 本地双击 HTML 与 GitHub Pages 共用普通打包脚本。

## 内容和素材

演示文字仅整理 heritage-data.js 已有内容，不加入统计排名或未经查证的文化事实。图形是代码绘制的形态示意，不是实测声波、录音或地理地图。未生成新 AI 图片，也未使用参考案例的图片或代码。案例启发了分层视差与滚动显形的表现方式。原有正文、资料图片、来源和地区/版本说明保留。
