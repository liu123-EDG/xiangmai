# 第二章图片目录

把图片放进这个目录，文件名与 `qiongnaieman/index.html` 里 `data-src` 的值对应即可。
**图片还没放进来时不会报错**：槽位会显示占位样式（斜纹底 + 提示文字），版面不变形。

## 三件事

1. **替换文件即可**，不用改 HTML。想换格式（png/webp）就改 `data-src` 的后缀。
2. **想加新槽位**：复制一段 `<figure class="slot reveal" data-src="..." data-label="..." style="--slot-ratio: 16 / 9">` 
   粘到任意位置，`--slot-ratio` 控制它的宽高比。
3. **图注**：每个槽位里的 `<figcaption>` 就是图注，直接改文字。
